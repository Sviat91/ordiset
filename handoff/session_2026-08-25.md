## Decisions Made / Reasoning Worth Preserving

- CSS Grid stacking (`display:grid` + `grid-area:1/1` on all locale variants, `visibility:hidden` on inactive ones) is now the established, reviewed, working pattern for **both** width reservation (`StableLabel`) and height reservation (`StableTextBlock`) — a grid track auto-sizes to the tallest/widest item sharing it even when items overlap, so this is native CSS, not a hack, and it doubles as the substrate for a cross-fade transition (swap is pure opacity/visibility, never `position`, since `position` can't be animated). Reuse this pattern for any future "don't let locale-dependent content size move things around" need instead of reinventing JS measurement.
- Cross-fade timing standard for this project: **350ms `ease-in-out`, both outgoing and incoming animating simultaneously** (not sequential) — this is what actually reads as "smooth/flowing" per explicit user testing; the original sequential 90ms/110ms pairing read as a "blink" despite being a real transition.
