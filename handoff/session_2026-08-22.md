## Decisions Made
- **`fixedViewport` mode over extending the existing auto-fit logic**: the existing `needH`/scale-to-fit design is monotonic-increasing by intent (so a page that briefly grows doesn't cause flicker), which is fundamentally wrong for a navigable, multi-page embed — any taller page permanently shrinks every other page afterward. Solved with a separate, mutually-exclusive fixed-viewport mode rather than patching the auto-fit math, since the two need genuinely different behavior (auto-height-fit vs. constant-size-with-internal-scroll).
- **`Math.max` (cover) over `Math.min` (contain)** for fitting the fixed 390×844 viewport into `PhoneFrame`'s screen box: `PhoneFrame`'s box isn't exactly 9:19.5 due to its 8px padding, so `contain` left a visible gap/bar on one axis (the reported "chin"); `cover` fills completely and only clips a sub-pixel sliver, invisible in practice, via the box's own `overflow: hidden`.
- **Runtime-injected `<style>` fix, never edit the vendored bundle on disk**: `public/demo-app/` is treated strictly as a black-box, pre-built third-party bundle. The sidebar clipping bug is real in that bundle's CSS, but the fix is injected into the iframe's `contentDocument` at runtime from `DemoStage.tsx` rather than hand-edited into `public/demo-app/assets/*`, so it survives a bundle rebuild as a no-op if the markup ever changes, and never risks corrupting the vendored asset.
- **`MutationObserver` over fixed-interval polling for auto-click**: a poll interval can lose the race against a slow/cold first load (the exact bug the user reported: admin embed sometimes not auto-navigating on first load); a `MutationObserver` reacts the instant the target button actually appears in the DOM, bounded by an overall timeout as a safety net.
- **1s `localStorage` poll over a `storage` event listener for cross-iframe sync (D7)**: live-verified that a same-origin child-iframe's write to `localStorage` does not fire a `storage` event on the parent window in this app, so event-based sync was ruled out in favor of direct polling.
